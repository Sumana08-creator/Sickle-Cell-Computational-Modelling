\# Sickle Cell Computational Modelling



\## Project Overview



This educational computational modelling project explores how Python can be used to investigate relationships between oxygen availability, haemoglobin S (HbS) polymerisation, and fetal haemoglobin (HbF) in sickle cell disease.



The project combines Python programming, mathematical modelling, numerical integration, data export, and scientific visualisation.



The long-term objective is to develop a reproducible computational framework informed by published research.



\## Current Progress



The project currently includes:



\- Python functions and numerical calculations.

\- An allosteric model of haemoglobin oxygen binding.

\- A model of oxygen binding by haemoglobin fibres.

\- Experiments exploring the influence of fetal haemoglobin.

\- Numerical integration using SciPy.

\- An exploratory HbS solubility calculation.

\- CSV export of calculated results.

\- Graph generation using Matplotlib.



\*\*Important:\*\* Implementing an equation in Python does not establish that its output is scientifically accurate. The solubility models and reference values require further verification against published experimental data.

\## Scientific Basis



The project draws on the following publication:



Henry et al. (2020). \*Allosteric control of hemoglobin S fiber formation by oxygen and its relation to the pathophysiology of sickle cell disease.\*



Published in the Proceedings of the National Academy of Sciences (PNAS).



DOI: 10.1073/pnas.1922004117



Full text:

https://pmc.ncbi.nlm.nih.gov/articles/PMC7334536/



The paper investigates the relationship between oxygen binding and the thermodynamic stability of HbS fibres. It describes oxygen-binding models and a thermodynamic relationship for calculating HbS solubility.



The project aims to implement and evaluate relevant relationships from the publication.



\## Oxygen-Binding Models



\### MWC Model



The MWC model represents cooperative oxygen binding by haemoglobin using an allosteric equilibrium between different conformational states.



Implementation: `mwc\_binding.py`



\### Fibre Oxygen-Binding Model



The fibre-binding function represents oxygen binding by haemoglobin fibres using a noncooperative binding relationship.



Implementation: `fiber\_binding.py`



\### Model Parameters



Parameters in the current implementation are taken from the specified experimental conditions described by Henry et al. (2020).



Parameter values must not be assumed to apply universally across temperatures, solution conditions, or biological environments.



\## Exploratory HbS Solubility Model



\### Purpose



The project includes an exploratory implementation intended to investigate how oxygen pressure and oxygen saturation relate to HbS solubility.



Implementation:

\- `solubility\_model.py`

\- `solubility\_integration.py`

\- `complete\_solubility\_model.py`



The complete model attempts to implement a differential form of the published thermodynamic relationship.



\### Current Status



The numerical implementation runs for the current test configuration and produces 101 calculated points.



However, the resulting solubility curve has not yet been validated against the experimental measurements presented in the original publication.



The reference solubility used by the current implementation is provisional.



The calculated results must therefore be treated as exploratory outputs, not validated scientific predictions.



\## Empirical Solubility Experiment



\### Purpose



The script `empirical\_solubility\_model.py` evaluates an empirical polynomial relationship between temperature, fractional oxygen saturation, and calculated HbS solubility.



The equation currently implemented is:



Cs = 0.321 - 0.00883T + 0.000125T²

&#x20;    + 0.0924y + 0.0980y³ + 0.235y¹⁵



Where:



\- `Cs` = calculated solubility in g/mL.

\- `T` = temperature in degrees Celsius.

\- `y` = fractional oxygen saturation, between 0 and 1.



\*\*Source verification required:\*\* The original source, units, experimental conditions, and applicability of this empirical equation must be verified before its results are interpreted as scientifically meaningful.



\### Current Demonstration



At a specified temperature of 25°C, the script calculates solubility estimates at 101 oxygen saturation levels.



The current implementation produces:



\- A CSV file containing calculated values.

\- A PNG graph showing the relationship between fractional oxygen saturation and calculated solubility.



These outputs are generated mathematically and are not new experimental measurements.
