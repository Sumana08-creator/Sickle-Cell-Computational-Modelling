# Sickle Cell Computational Modelling

## Project Overview

This project is a learning-based computational modelling project exploring how Python can be used to organise data, perform calculations, and visualise information relevant to scientific research.

The long-term goal is to investigate the relationship between oxygen availability, haemoglobin S (HbS) polymerisation, and fetal haemoglobin (HbF) in sickle cell disease using scientifically supported models.

## Current Progress

The current version demonstrates basic Python programming skills, including:

- Variables and lists
- Loops and conditional statements
- Basic statistical calculations
- Data visualisation using Matplotlib
- Saving graphs as image files

## Current Demonstration

The program uses illustrative values to practise Python programming and graph creation.

These values are not experimental measurements, clinical data, or validated biological predictions.

## Future Development

Planned development includes:

- Reviewing published scientific literature
- Identifying scientifically supported mathematical relationships
- Developing and testing a clearly defined computational model
- Exploring how model inputs affect predicted outputs
- Documenting assumptions, limitations, and results

## Scientific Disclaimer

This is an educational project under development. The current demonstration is not a validated model of sickle cell disease and must not be used for clinical decision-making.
